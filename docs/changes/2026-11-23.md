## CI: automatically submit WinGet updates from releases

- **Change:** After a successful manual installer release workflow, generate and submit an updated `SABL.SimplePDF` WinGet manifest PR using WingetCreate. Require explicit enablement and a repository secret; support manual retries by release tag.
- **Branch:** `ci/automate-winget-updates`.
- **Commit scope:** GitHub Actions WinGet updater, AAA workflow regression tests, and distribution instructions.
- **Tests:** `tests/test_winget_workflow.py` checks trigger gating, stable installer selection, token safety and manual retries. Live submission requires an approved first WinGet package, a token and `WINGET_ENABLED=true`.
